# Student Management System

A React + Vite application for managing student records, attendance, marks, and performance insights.

## Features

- Add, edit, and delete students
- Search students by name, ID, or course
- Sort student records
- Track attendance and leave counts
- Enter subject marks and compute total percentage and grade
- Landing page with app overview and professional layout

## Tech Stack

- React
- Vite
- React Router DOM
- CSS for styling and layout

## Installation

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Open the URL shown in the console to view the app.

## Build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Project structure

- `src/` - application source code
- `src/components/` - reusable UI components
- `src/pages/` - page views
- `src/assets/` - static images and SVGs
- `index.html` - application entry point
- `package.json` - project manifest
